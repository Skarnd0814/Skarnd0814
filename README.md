## 자기소개
저는 **게임 개발자**를 꿈꾸는 학생으로, 프로그래밍과 창의적 스토리텔링을 결합하여 새로운 경험을 만드는 데 열정을 가지고 있습니다.  
게임은 단순한 오락을 넘어, 사람들에게 감동과 몰입을 제공할 수 있는 매체라고 믿습니다.  
앞으로는 **게임 엔진 활용, 그래픽스 프로그래밍, 인공지능 기반 게임 시스템**을 연구하고 개발하는 데 집중하고자 합니다.
